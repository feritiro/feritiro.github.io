JP Notify.

An offline Japanese vocabulary notification app that displays kanji and meanings when the phone screen is off.

01 / OVERVIEW

Vocabulary practice through notifications

JP Notify displays random Japanese kanji and their meanings as flashcard-style notifications. The user can select JLPT levels N1 through N5.

PLATFORMAndroid
LOCAL STORAGESQLite database

02 / FEATURES

Implemented functionality

  • Random kanji and meaning notifications.
  • Selectable JLPT levels from N1 to N5.
  • Offline vocabulary data stored in SQLite.
  • Customizable notification layout.
