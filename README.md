# feritiro.github.io homepage starter

Copy `index.html`, `css/`, and `js/` into the root of the `feritiro.github.io` repository, preserving folder names. Commit to `main` to publish with GitHub Pages.

Before launch:
- Replace CSS-generated project art placeholders with real game screenshots.
- Add the project detail pages linked from the homepage (`projects/arpg.html` and `projects/jrpg.html`).
- Add confirmed LinkedIn and professional email links.
- Review all descriptions and technical claims.
